# Cars Dealership React UI

This project uses Vite and React. From this directory run `npm ci`, then `npm run build`. Django serves the generated `build/index.html` and assets. Use the root README for the three-service local launcher and tests. The implemented entry point is `src/main.jsx`; `src/App.jsx` renders the directory, account and review flows. `src/components/Register/Register.jsx` implements the five-field registration page.
